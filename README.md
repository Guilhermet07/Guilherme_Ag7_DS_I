## 🌎 Sobre o projeto

Este projeto foi desenvolvido em Python para classificar o perfil de consumo de água de diferentes tipos de imóveis.
O programa solicita o tipo de imóvel e o consumo mensal de água em metros cúbicos (m³). Com essas informações, o sistema apresenta uma mensagem de orientação de acordo com as regras de consumo definidas.

## 💻 Linguagem usada

🐍 Python

## 🚀 Instruções para executar o programa

1. Instale o Python no computador.
2. Faça o download ou clone este repositório.
3. Abra a pasta do projeto no terminal.
4. Entre na pasta "consumo-agua".
5. Execute o arquivo "app.py" com o comando: "python app.py"
6. Digite o tipo de imóvel solicitado.
7. Informe o consumo mensal de água em m³.
8. Confira a mensagem apresentada pelo programa.
